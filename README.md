# Morse Code Challenge

A small React game where you decode Morse code transmissions into science and technology words.

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the app for production:

```bash
npm run build
```

## How to Play

1. Read the Morse code transmission.
2. Type the decoded word.
3. Select **Check** to submit your answer.
4. Select **Randomize challenge** for a new word.
